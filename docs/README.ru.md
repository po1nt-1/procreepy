# procreepy

Превращает таймлапс, который Procreate уже записал внутрь `.procreate`, в
обычный MP4.

- Без перекодирования: кадры копируются, качество остаётся как у Procreate.
- Исходные `.procreate` никогда не изменяются.
- Один файл или целая папка за раз.
- Одна программа. Ни ffmpeg, ни Python, ни аккаунта, ни настройки.
- Работает офлайн на Windows, macOS и Linux.

## Подходит ли вам это

Используйте procreepy, если:

- у вас есть файлы `.procreate`;
- при рисовании **была включена запись таймлапса** (в Procreate она включена по
  умолчанию);
- вы хотите получить этот таймлапс как MP4 — выложить, смонтировать, сохранить;
- или хотите убрать данные таймлапса из проектов, чтобы они стали меньше.

procreepy **не может**:

- создать таймлапс, который не был записан, — он только извлекает уже
  существующий;
- восстановить таймлапс из слоёв или истории отмен;
- починить повреждённый файл `.procreate`;
- экспортировать готовое изображение (но может экспортировать послойный PSD,
  см. [Экспорт в PSD](#экспорт-в-psd)).

Не знаете, есть ли в файле таймлапс? [Проверьте](#проверка-файла-перед-конвертацией) —
это одна команда, которая ничего не создаёт.

## Что получится

Один файл на входе, одно видео на выходе:

```text
my-art.procreate  →  procreepy  →  my-art.mp4
```

Папка на входе — дерево видео и архив проектов на выходе:

```text
input/                          input_procreepy/
├── Cat.procreate         →     ├── mp4/
├── Landscape.procreate   →     │   ├── Cat.mp4
└── Sketch.procreate      →     │   ├── Landscape.mp4
                                │   └── Sketch.mp4
                                └── procreate.zip   (облегчённые проекты)
```

- В `mp4/` лежат видео.
- `procreate.zip` — копия каждой работы **с удалённым таймлапсом**: намного
  меньше по размеру, её можно импортировать обратно в Procreate. Всё остальное
  в проекте сохранено байт в байт. Это обычный zip с папкой `procreate/` внутри,
  готовый к переносу на iPad; флаг `--no-zip` оставляет на диске саму папку
  `procreate/` вместо архива.
- Папка вывода называется по имени входной (`input/` → `input_procreepy/`) и
  создаётся в каталоге, откуда вы запускаете команду. Укажите второй путь, чтобы
  выбрать её самостоятельно.
- Каждый результат сохраняет дату файла, из которого получен, поэтому повторный
  импорт проекта в Procreate не перетасовывает галерею.
- `input/` остаётся ровно таким, каким был.

## Установка

Скачайте готовую программу для своей системы со страницы релизов — Go и другие
инструменты сборки не нужны.

- GitLab: https://gitlab.com/po1nt-1/procreepy/-/releases
- GitHub: https://github.com/po1nt-1/procreepy/releases

Выберите файл под свой компьютер:

| Ваша система | Что скачать |
|---|---|
| Windows (большинство ПК) | `procreepy_<version>_windows_amd64.zip` |
| Windows на ARM | `procreepy_<version>_windows_arm64.zip` |
| Mac на Apple Silicon (M1–M5) | `procreepy_<version>_darwin_arm64.tar.gz` |
| Mac на Intel | `procreepy_<version>_darwin_amd64.tar.gz` |
| Linux (большинство ПК) | `procreepy_<version>_linux_amd64.tar.gz` |
| Linux на ARM (Raspberry Pi, Graviton) | `procreepy_<version>_linux_arm64.tar.gz` |
| Linux на 32-битном ARM | `procreepy_<version>_linux_arm.tar.gz` |

На Mac посмотреть, Apple Silicon у вас или Intel, можно в меню Apple → «Об этом
Mac».

### Windows

1. Скачайте `procreepy_<version>_windows_amd64.zip`.
2. Правый клик по скачанному файлу → **Извлечь все** → выберите папку, которую
   потом найдёте, например `Downloads\procreepy`.
3. Откройте эту папку, щёлкните по адресной строке сверху, наберите `cmd` и
   нажмите Enter. Откроется чёрное окно командной строки в этой папке.
4. Положите туда же файл `.procreate` и запустите:

   ```text
   procreepy.exe "My Artwork.procreate" "My Artwork.mp4"
   ```

   Кавычки нужны только если в имени есть пробелы.

**Про предупреждение SmartScreen.** Программа не подписана платным
сертификатом Microsoft, поэтому при первом запуске Windows может показать синее
окно «Система Windows защитила ваш компьютер» и назвать приложение
«неопознанным». Это не сообщение о вирусе — Windows показывает его для любой
программы, которую ещё недостаточно часто видел. Чтобы продолжить, нажмите
**Подробнее**, затем появившуюся кнопку **Выполнить в любом случае**. Если не
хотите этого делать, используйте [контейнерный образ](#docker--podman).

### macOS

1. Скачайте `.tar.gz` под свой процессор (`darwin_arm64` для Apple Silicon,
   `darwin_amd64` для Intel).
2. Откройте Терминал (Программы → Утилиты → Терминал) и перейдите в папку
   загрузок:

   ```bash
   cd ~/Downloads
   ```

3. Распакуйте и разрешите запуск:

   ```bash
   tar -xzf procreepy_*_darwin_*.tar.gz
   xattr -d com.apple.quarantine ./procreepy
   ```

   Строка с `xattr` снимает карантин, который macOS ставит на скачанные файлы.
   Без неё система откажется запускать программу, потому что она не нотаризована
   Apple.

4. Сконвертируйте файл:

   ```bash
   ./procreepy "My Artwork.procreate" "My Artwork.mp4"
   ```

Чтобы команда `procreepy` работала из любого места, перенесите её в PATH:
`sudo mv ./procreepy /usr/local/bin/`.

### Linux

```bash
tar -xzf procreepy_*_linux_amd64.tar.gz
./procreepy artwork.procreate artwork.mp4
```

Программа статически слинкована, поэтому работает в любом дистрибутиве
независимо от версии glibc. Установить для всех пользователей:
`sudo install -m 755 procreepy /usr/local/bin/`.

### Docker / Podman

Для каждого релиза публикуется контейнерный образ под `linux/amd64` и
`linux/arm64`. На Mac с Apple Silicon вариант arm64 выбирается автоматически.

```bash
docker run --rm -v "$PWD":/data -w /data \
  registry.gitlab.com/po1nt-1/procreepy:latest artwork.procreate artwork.mp4
```

`podman` подставляется вместо `docker` без изменений. Зафиксировать версию:
`:0.3.0` вместо `:latest` (в тегах образа нет префикса `v`). Подробности о
владельце файлов и прочем — в [usage.md](usage.md#container-usage).

### Сборка из исходников

Нужна только если вы хотите менять код. См. [development.md](development.md).

### Проверка загрузки (необязательно)

С каждым релизом публикуется `CHECKSUMS.txt`. Чтобы убедиться, что файл скачался
целиком, выведите его хеш и сравните с соответствующей строкой:

```bash
sha256sum procreepy_0.3.0_linux_amd64.tar.gz    # Linux
shasum -a 256 procreepy_0.3.0_darwin_arm64.tar.gz   # macOS
grep darwin_arm64 CHECKSUMS.txt                 # ожидаемое значение
```

В Windows: `certutil -hashfile procreepy_0.3.0_windows_amd64.zip SHA256`.

Значения должны совпасть. Шаг необязательный — он выявляет обрезанную или
подменённую загрузку, не более.

## Конвертация одного файла

```bash
procreepy artwork.procreate artwork.mp4
```

Результат:

```text
artwork.mp4
```

Исходный `artwork.procreate` не изменяется. Если `artwork.mp4` уже существует,
он будет заменён — но только после того, как новое видео записано полностью.

Можно указать папку как назначение и позволить procreepy выбрать имя:

```bash
procreepy artwork.procreate videos/
```

Результат: `videos/artwork.mp4`. Папка должна существовать заранее.

## Конвертация папки

```bash
procreepy input/
```

Читает каждый `.procreate` в `input/` и пишет в `input_procreepy/`, как показано
в разделе [Что получится](#что-получится). Чтобы выбрать назначение самому:

```bash
procreepy input/ ~/Videos/timelapses
```

Чтобы обойти и вложенные папки (их структура повторяется на выходе):

```bash
procreepy -r input/ output/
```

Что происходит по ходу работы:

- Прогресс печатается по одной строке на файл.
- Для файла, в котором таймлапс не записывался, всё равно создаётся облегчённый
  проект (и PSD при `--psd`) — пропускается только видео, с отметкой в журнале, и
  работа продолжается.
- Повреждённый файл отмечается как ошибка, обработка остальных продолжается, а
  команда завершается с кодом `1`, чтобы это заметили скрипты.
- Повторный запуск той же команды не делает работу заново: работы, результаты
  которых уже на месте, пропускаются. Добавьте `-f`, чтобы пересобрать их.
- После запуска без ошибок облегчённые проекты упаковываются в `procreate.zip`, а
  сама папка `procreate/` удаляется. Запуск, где была хоть одна ошибка, оставляет
  папку нераспакованной — её можно изучить и продолжить работу. Флаг `--no-zip`
  всегда оставляет папку.

## Проверка файла перед конвертацией

Обе команды не создают видео и ничего не меняют.

**Есть ли в файле таймлапс и какой он длины?**

```bash
procreepy --list artwork.procreate
```

```text
input: artwork.procreate
segments: 18

1  video/segments/segment-1.mp4
2  video/segments/segment-2.mp4
...
```

`--list` читает оглавление файла. Работает мгновенно и отвечает на вопрос, есть
ли таймлапс вообще.

**Сконвертируется ли файл на самом деле?**

```bash
procreepy --verify artwork.procreate
```

`--verify` идёт дальше: читает каждый сегмент таймлапса, проверяет его на
повреждения и убеждается, что сегменты можно склеить без перекодирования.
Медленнее, чем `--list`, и даёт честный ответ на вопрос «сконвертируется ли это
нормально?».

Обе команды принимают и папку — тогда отчёт строится по всем файлам в ней.

## Экспорт в PSD

```bash
procreepy --psd input/ output/
```

Рядом с каждым видео и облегчённым проектом записывается `output/psd/NAME.psd` —
послойный файл Photoshop, который открывается в Photoshop, Affinity Photo, GIMP
и подобных редакторах.

`--psd` работает **только с папкой на входе**. С одиночным файлом команда
останавливается: `--psd needs a directory INPUT; it writes into OUTPUT/psd/`.

PSD — это экспорт, а не точная копия. Сохраняются дерево слоёв, структура и
порядок групп, имена, видимость, прозрачность, режимы наложения и само
изображение; **не** сохраняются маски слоёв, обтравочные связи и редактируемый
текст. Прочитайте [что PSD сохраняет, а что теряет](usage.md#export-a-psd),
прежде чем использовать его для финальной работы. Эталоном держите файл
`.procreate`.

PSD также содержит встроенное превью, поэтому приложения, которые его читают
(Photoshop, Affinity, GIMP), показывают миниатюру. Само по себе это **не**
заставляет Проводник Windows рисовать миниатюру: ему нужен зарегистрированный
обработчик миниатюр для `.psd`, которого Windows не поставляет (его добавляет
Photoshop или пакет вроде SageThumbs), а для `.procreate` его нет вовсе.

## Что происходит с вашими файлами

- **Исходники никогда не изменяются.** procreepy открывает `.procreate` только
  для чтения. Всё, что он создаёт, пишется в другое место.
- **Ничего не остаётся недописанным.** Каждый результат сначала собирается во
  временном файле и ставится на место только целиком. Прерванный или упавший
  запуск не оставит битого видео и не испортит то, что уже лежало на месте.
- **Для папки результаты публикуются комплектом на работу.** Видео,
  облегчённый проект и PSD для одной работы появляются вместе или не появляются
  вовсе — видео без проекта вы не получите.
- **Даты переносятся.** Каждый результат — видео, облегчённый проект и PSD —
  получает дату изменения исходного `.procreate` (а в Windows ещё и дату
  создания), поэтому проект, импортированный обратно в Procreate, остаётся на
  своём месте в галерее.
- **Повторный запуск безопасен.** Готовые работы пропускаются — независимо от
  того, лежат ли проекты папкой или уже упакованы в `procreate.zip`. Комплект,
  оставшийся неполным после прерванного запуска, пересобирается целиком. `-f`
  пересобирает всё.
- **Конвертация одного файла заменяет файл назначения**, если он есть, — после
  того как новое видео записано полностью.
- **Большим файлам нужно место под временные данные.** Крупные таймлапсы
  собираются через временный файл. Если места не хватает, укажите `--tmpdir` на
  диск посвободнее.

## Если что-то пошло не так

| Что вы видите | Что это значит |
|---|---|
| `procreepy: command not found` | Вы не в той папке, куда распаковали программу; на macOS/Linux запускайте `./procreepy`. |
| `no video/segments in the archive` | В этом файле таймлапс не записывался. Восстановить его нельзя. |
| `input is not a valid ZIP archive` | Это не файл `.procreate` либо загрузка/копия обрезана. |
| `segment ... is corrupted inside the archive` | Данные таймлапса повреждены. |
| `segments are incompatible` | Таймлапс записан через смену холста или качества, склеить без перекодирования нельзя. |
| `refusing to write video data to a terminal` | Укажите имя файла назначения или перенаправьте вывод через `> out.mp4`. |
| `Система Windows защитила ваш компьютер` | См. [примечание про SmartScreen](#windows). |
| `no space left` / ошибки записи | Укажите `--tmpdir` на диск, где больше свободного места. |

Каждый случай — с точным симптомом и действиями — разобран в
[troubleshooting.md](troubleshooting.md).

## Справка по командам

```text
procreepy [options] INPUT [OUTPUT]
```

`INPUT` — файл `.procreate`, папка с ними или `-` для стандартного ввода.
`OUTPUT` — имя файла, папка или `-` для стандартного вывода. Для одиночного
файла пропущенный `OUTPUT` означает вывод видео в стандартный поток; для папки
по умолчанию берётся `<INPUT>_procreepy/` в текущем каталоге.

| Опция | Что делает | К чему применима |
|---|---|---|
| `-h`, `--help` | показать справку и выйти | всегда |
| `--version` | показать версию и выйти | всегда |
| `--list` | перечислить сегменты таймлапса; видео не создавать | файл или папка |
| `--verify` | проверить каждый сегмент; видео не создавать | файл или папка |
| `-r`, `--recursive` | обходить и вложенные папки | только папка на входе |
| `-f`, `--force` | перезаписывать уже существующие результаты | только папка на входе |
| `--psd` | дополнительно экспортировать послойный PSD на каждую работу | только папка на входе |
| `--no-zip` | оставить проекты папкой `procreate/`, а не упаковывать в `procreate.zip` | только папка на входе |
| `--strict` | считать пропуски в нумерации сегментов ошибкой, а не предупреждением | файл или папка |
| `--tmpdir DIR` | куда складывать временные файлы | всегда |
| `-q`, `--quiet` | печатать только предупреждения и ошибки | всегда |
| `--` | прекратить разбор опций; остальное считать именами файлов | всегда |

Полная справка с примерами, форматами вывода и кодами выхода:
[usage.md](usage.md).

## Как это работает

Файл `.procreate` — это ZIP-архив. Когда запись таймлапса включена, Procreate
хранит готовое видео внутри него, разбитое на нумерованные части
(`video/segments/segment-1.mp4`, `segment-2.mp4`, …). procreepy читает эти части
прямо из архива, сортирует их по номерам, проверяет, что у них одинаковые кодек
и холст, и сшивает в один MP4, копируя кадры без изменений. Ничего не
рендерится и не перекодируется — поэтому быстро и без потерь.

Путь таймлапса никогда не заглядывает в ваши слои. Их читает только `--psd`.

Подробности — сборка MP4, атомарная запись, стратегия временных файлов, точность
PSD: [how-it-works.md](how-it-works.md).
