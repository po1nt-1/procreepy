# procreepy

يحوّل تسجيل الزمن المتسارع (timelapse) الذي سجّله Procreate بالفعل داخل ملف
`.procreate` إلى ملف MP4 عادي.

- بلا إعادة ترميز: تُنسخ الإطارات كما هي، فيحتفظ الفيديو بجودة Procreate نفسها.
- ملفات `.procreate` الأصلية لا تُعدَّل أبدًا.
- ملف واحد أو مجلد كامل في المرة الواحدة.
- برنامج واحد فقط. لا ffmpeg، ولا Python، ولا حساب، ولا شيء لإعداده.
- يعمل دون اتصال على Windows وmacOS وLinux.

## هل هذه الأداة مناسبة لك؟

استخدم procreepy إذا:

- كانت لديك ملفات `.procreate`؛
- كان **تسجيل الزمن المتسارع مفعّلًا** أثناء الرسم (وهو مفعّل افتراضيًا في
  Procreate)؛
- أردت ذلك التسجيل كملف MP4 لنشره أو تحريره أو الاحتفاظ به؛
- أو أردت إزالة بيانات التسجيل من مشاريعك لتصغير حجمها.

ولا يستطيع procreepy:

- إنشاء تسجيل لم يُسجَّل قط — فهو يستخرج الموجود فقط؛
- إعادة بناء تسجيل من الطبقات أو من سجل التراجع؛
- إصلاح ملف `.procreate` متضرر؛
- تصدير صورة نهائية للعمل (لكنه يصدّر ملف PSD بطبقات، انظر
  [التصدير إلى PSD](#التصدير-إلى-psd)).

لست متأكدًا من وجود تسجيل في ملفك؟ [افحصه أولًا](#فحص-الملف-قبل-التحويل) — أمر
واحد لا يُنشئ أي شيء.

## ما ستحصل عليه

ملف واحد في المدخل، فيديو واحد في المخرج:

```text
my-art.procreate  →  procreepy  →  my-art.mp4
```

مجلد في المدخل، وفي المخرج شجرة فيديو وأرشيف مشاريع:

```text
input/                          input_procreepy/
├── Cat.procreate         →     ├── mp4/
├── Landscape.procreate   →     │   ├── Cat.mp4
└── Sketch.procreate      →     │   ├── Landscape.mp4
                                │   └── Sketch.mp4
                                └── procreate.zip   (المشاريع المخفَّفة)
```

- يحتوي `mp4/` على مقاطع الفيديو.
- ويحتوي `procreate.zip` على نسخة من كل عمل **بعد إزالة التسجيل منه**: أصغر بكثير،
  ويمكنك استيرادها إلى Procreate مرة أخرى. وكل ما عدا ذلك في المشروع محفوظ بايتًا
  ببايت. وهو ملف zip عادي بداخله مجلد `procreate/`، جاهز للنقل إلى iPad؛ ويترك
  الخيار `--no-zip` ذلك المجلد `procreate/` على القرص بدلًا من الأرشيف.
- يُسمَّى مجلد المخرج باسم مجلد المدخل (`input/` → `input_procreepy/`) ويُنشأ في
  المجلد الذي تشغِّل منه الأمر. أعطِ مسارًا ثانيًا لتختاره بنفسك.
- يحتفظ كل مخرج بتاريخ الملف الذي جاء منه، فإعادة استيراد مشروع إلى Procreate لا
  تعيد ترتيب معرض أعمالك.
- ويبقى `input/` كما كان تمامًا.

## التثبيت

نزّل برنامجًا جاهزًا لنظامك من صفحة الإصدارات — لا تحتاج إلى Go ولا إلى أي أدوات
بناء.

- GitLab: https://gitlab.com/po1nt-1/procreepy/-/releases
- GitHub: https://github.com/po1nt-1/procreepy/releases

اختر الملف المطابق لحاسبك:

| نظامك | التنزيل |
|---|---|
| Windows (معظم الأجهزة) | `procreepy_<version>_windows_amd64.zip` |
| Windows على ARM | `procreepy_<version>_windows_arm64.zip` |
| Mac بمعالج Apple Silicon (M1–M5) | `procreepy_<version>_darwin_arm64.tar.gz` |
| Mac بمعالج Intel | `procreepy_<version>_darwin_amd64.tar.gz` |
| Linux (معظم الأجهزة) | `procreepy_<version>_linux_amd64.tar.gz` |
| Linux على ARM (Raspberry Pi، Graviton) | `procreepy_<version>_linux_arm64.tar.gz` |
| Linux على ARM بـ 32 بت | `procreepy_<version>_linux_arm.tar.gz` |

على أجهزة Mac، يبيّن لك قائمة Apple ← «حول هذا الماك» إن كان معالجك Apple Silicon
أم Intel.

### Windows

1. نزّل `procreepy_<version>_windows_amd64.zip`.
2. انقر بالزر الأيمن على الملف المنزَّل ← **استخراج الكل** ← واختر مجلدًا تجده
   لاحقًا، مثل `Downloads\procreepy`.
3. افتح ذلك المجلد، ثم انقر على شريط العنوان في الأعلى، واكتب `cmd` واضغط Enter.
   ستُفتح نافذة سوداء لموجّه الأوامر داخل المجلد نفسه.
4. ضع ملف `.procreate` في المجلد نفسه ونفّذ:

   ```text
   procreepy.exe "My Artwork.procreate" "My Artwork.mp4"
   ```

   وعلامات التنصيص ضرورية فقط إذا احتوى الاسم على مسافات.

**عن تحذير SmartScreen.** البرنامج غير موقَّع بشهادة مدفوعة من Microsoft، لذا قد
يُظهر Windows في أول تشغيل نافذة زرقاء تقول «Windows protected your PC» وتصفه
بتطبيق «غير معروف». وهذا ليس إبلاغًا عن فيروس — فنظام Windows يُظهره لأي برنامج لم
يره بعد عددًا كافيًا من المرات. للمتابعة اضغط **More info** ثم زر **Run anyway**
الذي يظهر. وإن كنت تفضّل تجنّب ذلك، فاستخدم [صورة الحاوية](#docker--podman).

### macOS

1. نزّل ملف `.tar.gz` الموافق لمعالجك (`darwin_arm64` لـ Apple Silicon،
   و`darwin_amd64` لـ Intel).
2. افتح Terminal (التطبيقات ← الأدوات ← Terminal) وانتقل إلى مجلد التنزيلات:

   ```bash
   cd ~/Downloads
   ```

3. فُكّ الضغط واسمح بالتشغيل:

   ```bash
   tar -xzf procreepy_*_darwin_*.tar.gz
   xattr -d com.apple.quarantine ./procreepy
   ```

   يزيل سطر `xattr` سمة الحجر الصحي الموضوعة على الملفات المنزَّلة. وبدونه يرفض
   macOS تشغيل البرنامج، لأنه غير موثَّق (notarized) من Apple.

4. حوّل ملفًا:

   ```bash
   ./procreepy "My Artwork.procreate" "My Artwork.mp4"
   ```

ولتتمكن من كتابة `procreepy` من أي مكان، انقله إلى PATH:
`sudo mv ./procreepy /usr/local/bin/`.

### Linux

```bash
tar -xzf procreepy_*_linux_amd64.tar.gz
./procreepy artwork.procreate artwork.mp4
```

البرنامج مرتبط ارتباطًا ساكنًا، فيعمل على أي توزيعة بغض النظر عن إصدار glibc لديها.
ولتثبيته لجميع المستخدمين: `sudo install -m 755 procreepy /usr/local/bin/`.

### Docker / Podman

تُنشر صورة حاوية مع كل إصدار، لمعماريتي `linux/amd64` و`linux/arm64`. وعلى أجهزة
Mac بمعالج Apple Silicon يُنتقى متغيّر arm64 تلقائيًا.

```bash
docker run --rm -v "$PWD":/data -w /data \
  registry.gitlab.com/po1nt-1/procreepy:latest artwork.procreate artwork.mp4
```

ويحلّ `podman` محلّ `docker` حرفيًا. ولتثبيت إصدار معيّن استخدم `:0.3.0` بدلًا من
`:latest` (وسوم الصورة لا تحمل البادئة `v`). وتفاصيل ملكية الملفات وغيرها في
[usage.md](usage.md#container-usage).

### البناء من المصدر

لا تحتاجه إلا إن أردت تعديل الكود. انظر [development.md](development.md).

### التحقق من التنزيل (اختياري)

يُنشر مع كل إصدار ملف `CHECKSUMS.txt` أيضًا. وللتأكد من وصول التنزيل سليمًا، اطبع
بصمة ملفك وقارنها بالسطر المقابل:

```bash
sha256sum procreepy_0.3.0_linux_amd64.tar.gz    # Linux
shasum -a 256 procreepy_0.3.0_darwin_arm64.tar.gz   # macOS
grep darwin_arm64 CHECKSUMS.txt                 # القيمة المتوقعة
```

وعلى Windows: `certutil -hashfile procreepy_0.3.0_windows_amd64.zip SHA256`.

ويجب أن تتطابق القيمتان تمامًا. وهذه خطوة اختيارية — تكشف تنزيلًا مقطوعًا أو
مُتلاعبًا به، لا أكثر.

## تحويل ملف واحد

```bash
procreepy artwork.procreate artwork.mp4
```

النتيجة:

```text
artwork.mp4
```

ولا يُعدَّل الأصل `artwork.procreate`. وإن كان `artwork.mp4` موجودًا فسيُستبدل، لكن
بعد كتابة الفيديو الجديد كاملًا فقط.

ويمكنك أيضًا إعطاء مجلد كهدف وترك التسمية لـ procreepy:

```bash
procreepy artwork.procreate videos/
```

النتيجة: `videos/artwork.mp4`. ويجب أن يكون المجلد موجودًا مسبقًا.

## تحويل مجلد

```bash
procreepy input/
```

يقرأ كل ملف `.procreate` في `input/` ويكتب في `input_procreepy/`، كما هو مبيّن في
[ما ستحصل عليه](#ما-ستحصل-عليه). ولاختيار الهدف بنفسك:

```bash
procreepy input/ ~/Videos/timelapses
```

ولتضمين المجلدات الفرعية (تُحاكى بنيتها في المخرج):

```bash
procreepy -r input/ output/
```

ما يحدث أثناء التنفيذ:

- يُبلَّغ عن التقدّم لكل ملف بسطر واحد.
- الملف الذي لم يُسجَّل تسجيله قط يُنتِج مع ذلك مشروعه المخفَّف (وملف PSD الخاص به
  مع `--psd`) — ويُتجاوز الفيديو وحده، مع ملاحظة، ويستمر التنفيذ.
- والملف المتضرر يُبلَّغ عنه كخطأ، ويستمر التنفيذ مع بقية الملفات، وينتهي الأمر
  برمز خروج `1` لتلاحظه السكربتات.
- وتنفيذ الأمر نفسه مرتين لا يعيد العمل المنجز: فالأعمال التي صارت نتائجها موجودة
  تُتجاوز. أضف `-f` لإعادة بنائها رغم ذلك.
- بعد تنفيذ بلا أي إخفاق، تُحزَم المشاريع المخفَّفة في `procreate.zip` ويُحذف مجلد
  `procreate/`. أما التنفيذ الذي يقع فيه أي إخفاق فيُبقي المجلد دون حزم لتتمكن من
  فحصه ومتابعة العمل. ويُبقي `--no-zip` المجلد دائمًا.

## فحص الملف قبل التحويل

كلا الأمرين لا يُنشئ فيديو ولا يغيّر شيئًا.

**هل في هذا الملف تسجيل، وما طوله؟**

```bash
procreepy --list artwork.procreate
```

```text
input: artwork.procreate
segments: 18

1  video/segments/segment-1.mp4
2  video/segments/segment-2.mp4
...
```

يقرأ `--list` فهرس الملف. وهو فوري، ويخبرك إن كان هناك تسجيل من أصله.

**هل سينجح التحويل فعلًا؟**

```bash
procreepy --verify artwork.procreate
```

ويذهب `--verify` أبعد: يقرأ كل مقطع من التسجيل، ويفحصه بحثًا عن تلف، ويتأكد أن
المقاطع قابلة للوصل دون إعادة ترميز. وهو أبطأ من `--list`، وهو الجواب الصادق على
سؤال «هل سيُحوَّل هذا نظيفًا؟».

ويقبل كلاهما مجلدًا أيضًا، فيُبلّغان عن كل ملف داخله.

## التصدير إلى PSD

```bash
procreepy --psd input/ output/
```

إلى جانب كل فيديو ومشروع مخفَّف، يُكتب `output/psd/NAME.psd`: ملف Photoshop بطبقات
يُفتح في Photoshop وAffinity Photo وGIMP وما شابهها.

ويعمل `--psd` **مع مجلد في المدخل فقط**. وبملف واحد يتوقف مع الرسالة
`--psd needs a directory INPUT; it writes into OUTPUT/psd/`.

وملف PSD تصديرٌ لا نسخة مطابقة. فهو يحفظ شجرة الطبقات، وبنية المجموعات وترتيبها،
والأسماء، والظهور، والعتامة، وأنماط الدمج، والصورة نفسها؛ ولا يحفظ أقنعة الطبقات،
ولا علاقات القَصّ، ولا النص القابل للتحرير. اقرأ
[ما يحفظه PSD وما يفقده](usage.md#export-a-psd) قبل استخدامه في عمل نهائي. واجعل
ملف `.procreate` هو النسخة الأم دائمًا.

كما يُضمِّن PSD صورة معاينة صغيرة، فتعرض التطبيقات التي تقرؤه (Photoshop وAffinity
وGIMP) صورة مصغَّرة. لكن هذا وحده **لا** يجعل مستكشف Windows يرسم صورة مصغَّرة: إذ
يحتاج المستكشف إلى معالج صور مصغَّرة مُسجَّل لنوع `.psd` لا يأتي مع Windows (يوفّره
Photoshop أو حزمة مثل SageThumbs)، ولا يوجد أي معالج لنوع `.procreate` إطلاقًا.

## ما يحدث لملفاتك

- **أصولك لا تُعدَّل أبدًا.** يفتح procreepy ملفات `.procreate` للقراءة فقط. وكل ما
  يُنتجه يُكتب في مكان آخر.
- **لا يبقى شيء مكتوبًا نصف كتابة.** تُبنى كل نتيجة أولًا في ملف مؤقت، ولا توضع في
  موضعها إلا بعد تمامها. والتنفيذ المقطوع أو الفاشل لا يترك فيديو معطوبًا ولا يُفسد
  ملفًا كان موجودًا.
- **تنفيذ المجلد ينشر لكل عمل كمجموعة.** فالفيديو والمشروع المخفَّف وملف PSD لعمل
  واحد تظهر مجتمعة أو لا تظهر — ولن تحصل أبدًا على فيديو بلا مشروعه.
- **التواريخ تُنقَل.** يأخذ كل مخرج — الفيديو والمشروع المخفَّف وملف PSD — تاريخ
  تعديل ملف `.procreate` الذي جاء منه (وتاريخ الإنشاء أيضًا على Windows)، فيحتفظ
  المشروع المُعاد استيراده إلى Procreate بمكانه في المعرض.
- **إعادة التنفيذ آمنة.** تُتجاوز الأعمال المنجزة، سواء بقيت المشاريع مجلدًا أو
  صارت محزومة في `procreate.zip`. وأي مجموعة بقيت ناقصة بسبب تنفيذ مقطوع تُعاد
  بناءً كاملًا. ويعيد `-f` بناء كل شيء.
- **تحويل ملف واحد يستبدل الهدف** إن كان موجودًا، بعد كتابة الفيديو الجديد كاملًا.
- **الملفات الكبيرة تحتاج مساحة مؤقتة.** فالتسجيلات الكبيرة تُجمَّع عبر ملف مؤقت.
  وإذا نقصت المساحة فوجّه `--tmpdir` إلى قرص أوسع.

## إذا حدث خطأ ما

| ما ترى | معناه |
|---|---|
| `procreepy: command not found` | أنت لست في المجلد الذي فككت فيه الضغط؛ استخدم `./procreepy` على macOS/Linux. |
| `no video/segments in the archive` | لم يُسجَّل أي تسجيل في ذلك الملف. ولا يمكن استعادته. |
| `input is not a valid ZIP archive` | ليس ملف `.procreate`، أو أن التنزيل/النسخ مقطوع. |
| `segment ... is corrupted inside the archive` | بيانات التسجيل متضررة. |
| `segments are incompatible` | سُجّل التسجيل عبر تغيير في اللوحة أو الجودة، فلا يمكن وصله دون إعادة ترميز. |
| `refusing to write video data to a terminal` | أعطِ اسم ملف للهدف، أو أعد التوجيه بـ `> out.mp4`. |
| `Windows protected your PC` | انظر [ملاحظة SmartScreen](#windows). |
| `no space left` / أخطاء كتابة | استخدم `--tmpdir` على قرص فيه مساحة أكبر. |

وكل حالة من هذه، مع عَرَضها الدقيق وما يجب فعله، موجودة في
[troubleshooting.md](troubleshooting.md).

## مرجع الأوامر

```text
procreepy [options] INPUT [OUTPUT]
```

`INPUT` هو ملف `.procreate`، أو مجلد يحتويها، أو `-` للمدخل القياسي. و`OUTPUT` هو
اسم ملف، أو مجلد، أو `-` للمخرج القياسي. وفي حالة الملف الواحد، يعني إغفال `OUTPUT`
كتابة الفيديو إلى المخرج القياسي؛ وفي حالة المجلد يكون الافتراضي
`<INPUT>_procreepy/` في المجلد الحالي.

| الخيار | وظيفته | ينطبق على |
|---|---|---|
| `-h`، `--help` | إظهار المساعدة ثم الخروج | دائمًا |
| `--version` | إظهار الإصدار ثم الخروج | دائمًا |
| `--list` | سرد مقاطع التسجيل؛ دون كتابة فيديو | ملف أو مجلد |
| `--verify` | فحص كل مقطع؛ دون كتابة فيديو | ملف أو مجلد |
| `-r`، `--recursive` | معالجة المجلدات الفرعية أيضًا | مدخل مجلد فقط |
| `-f`، `--force` | الكتابة فوق النتائج الموجودة | مدخل مجلد فقط |
| `--psd` | تصدير ملف PSD بطبقات لكل عمل أيضًا | مدخل مجلد فقط |
| `--no-zip` | ترك المشاريع كمجلد `procreate/` بدل حزمها في `procreate.zip` | مدخل مجلد فقط |
| `--strict` | اعتبار الثغرات في ترقيم المقاطع أخطاءً لا تحذيرات | ملف أو مجلد |
| `--tmpdir DIR` | مكان وضع الملفات المؤقتة | دائمًا |
| `-q`، `--quiet` | طباعة التحذيرات والأخطاء فقط | دائمًا |
| `--` | إيقاف قراءة الخيارات؛ واعتبار الباقي أسماء ملفات | دائمًا |

المرجع الكامل مع الأمثلة وصِيَغ المخرجات ورموز الخروج: [usage.md](usage.md).

## كيف يعمل

ملف `.procreate` هو أرشيف ZIP. وعندما يكون تسجيل الزمن المتسارع مفعّلًا، يخزّن
Procreate الفيديو الجاهز داخله، مقسّمًا إلى أجزاء مرقَّمة
(`video/segments/segment-1.mp4`، `segment-2.mp4`، …). ويقرأ procreepy هذه الأجزاء
من الأرشيف مباشرة، ويرتّبها رقميًا، ويتحقق من أنها تتشارك المرمِّز ومقاس اللوحة،
ثم يخيطها في ملف MP4 واحد بنسخ الإطارات كما هي. فلا يُصيَّر شيء ولا يُعاد ترميز
شيء — ولهذا فهو سريع وبلا فقدان.

ومسار التسجيل لا ينظر في طبقاتك قط. ولا يقرأ العمل نفسه إلا `--psd`.

التفاصيل — تجميع MP4، والكتابة الذرية، واستراتيجية الملفات المؤقتة، ودقة PSD:
[how-it-works.md](how-it-works.md).

## التطوير

البناء والاختبارات والتغطية والترجمة المتقاطعة والإصدار والتكامل المستمر:
[development.md](development.md).

المتطلبات هي Go (الإصدار مذكور في [`go.mod`](../go.mod)) و`make`. ولا توجد في
المشروع أي تبعيات خارجية.

```bash
make check   # فحص التنسيق + البناء + vet + مجموعة الاختبارات كاملة
```
